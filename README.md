# Christmas Gala — invitation prototype v0.1

A formal Christmas Ball invitation built with HTML, CSS and vanilla JavaScript. No build tooling required. Original design featuring forest green, burgundy, champagne gold and ivory, with an animated sealed envelope and responsive invitation.

## Preview
Open `index.html` in a browser, or enable GitHub Pages under Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. Expected project URL: https://wo0f27.github.io/christmas-gala/ (after deployment).

## Personalization
Edit the `EVENT` object near the bottom of `index.html`: host, theme, message, date, time, venue, attire, attireNote, deadline, contact, program and programNote. The event details and program are currently placeholders, not confirmed information. Set `startISO` to a valid ISO timestamp with timezone offset to activate the countdown. Set `rsvpUrl` to a real HTTPS form URL to enable RSVP; no responses are collected by the prototype itself. The displayed color palette is provisional, not a dress requirement.

The design uses Google Fonts with local serif/sans-serif fallbacks. All other visual elements are CSS and HTML. No third-party invitation template code was copied.
